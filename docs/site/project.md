# Project

- **Contributing.** `CONTRIBUTING.md` in the repository explains how to set up, test and send
  a change, including how to add a model, a bench task, an API codec or an engine adapter.
- **Security.** Report vulnerabilities privately, as `SECURITY.md` describes.
- **Code of conduct.** Everyone taking part follows `CODE_OF_CONDUCT.md`.
- **License.** Stepswitch is released under the MIT license (`LICENSE`).
- **Releases.** Each release's notes are generated from the commit history, which follows
  conventional commits (`cliff.toml`).
- **Design records.** These live in the repository, not on this site, because they discuss
  plans, hypotheses and other projects:
  - the product spec, `docs/SPEC.md`;
  - the architecture, `docs/ARCHITECTURE.md`;
  - the decision records, `docs/decisions/`;
  - the research notes, `docs/RESEARCH.md`;
  - the progress log, `docs/PROGRESS.md`.

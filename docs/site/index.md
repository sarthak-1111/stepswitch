# Stepswitch

Stepswitch is an open-source orchestrator for coding agents. It picks a model and a harness for
each task, and for each step inside a task. It checks the result with your project's own tests
and keeps a ledger of what each step cost.

The [quickstart](quickstart.md) gets a CPU-only machine from install to a finished task. The
[examples](examples.md) show configurations for common setups.
